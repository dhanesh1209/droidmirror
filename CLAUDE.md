# DroidMirror

Mac menu-bar app (Swift package), Android companion (`android/`), and MCP/CLI automation (`automation/`).
See PLAN.md and README.md.

## Design System
Always read DESIGN.md before making any visual or UI decision (menu, Mac windows, Android screen).
Fonts, colours, spacing, menu structure and tone are defined there. Do not deviate without asking the user.
In review or QA, flag any code that does not match DESIGN.md.
